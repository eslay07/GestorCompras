# Privacidad

La aplicación actual permite integrar correo, documentos y portales mediante configuración propia. Las conexiones y operaciones reales requieren autorización y credenciales de cada organización; no se incluyen en el repositorio.

Las 25 capturas del README se generaron en una base temporal con datos de demostración, sin conectarse a buzones ni portales. Proveedores, correos, RUC, responsables y rutas privadas están ocultos o sustituidos.

La edición pública excluye bases operativas, buzones, adjuntos, credenciales, registros de ejecución, perfiles personalizados del instalador e identificadores privados de documentos y almacenamiento. El instalador público usa un perfil vacío y conserva los datos existentes al actualizar.

Los datos activos permanecen fuera del código. No publique las carpetas locales de datos, diagnósticos o respaldos. Los catálogos y credenciales deben configurarse en cada equipo.
